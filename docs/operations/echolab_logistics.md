# Lab Logistics

## Letters of rec from Marshall

Marshall has a system for letter of rec requests that involves working with him and his (fully remote) assistant Chumi (peraltad@stanford.edu).

Anyone who needs recommendation letters should maintain a Google spreadsheet with two tabs and share it with Chumi and Marshall.

### Tab 1: Applications

Include the following columns:

- Where you are applying
- Position type (e.g., PhD program, postdoc)
- Date the letter request was sent
- Letter due date

Sort applications by letter due date, with the most recent deadline first.

### Tab 2: Letter Materials

Include:

- Link to the most up-to-date personal statement
- Link to your CV
- Bullet points describing anything specific you would like highlighted in the letter that might otherwise be missed

This is not the time to be modest. The goal is to make it as easy as possible to write a strong letter on your behalf.

### Requesting Letters

- Use Marshall's email address when submitting letter requests.
- Chumi has access to Marshall's email and will upload the letters.
- For a **new type of letter** (e.g., Marshall is writing for you for the first time), provide **at least two weeks' notice**, and ideally more.
- For an **additional application of a type for which a letter has already been written** (e.g., another PhD program after the initial graduate-school letter is complete), less lead time is typically needed.
