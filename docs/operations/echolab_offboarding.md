# Configuring Sherlock Access

Before you lose Sherlock access, double-check group permissions on everything you created under `/home/groups/mburke` — run `chmod -R g+w` (and confirm group ownership is `mburke`) on any directory or file that isn't already group-writable. See [Computing: `$GROUP_HOME` and shared permissions](../research/computing.md#group_home_and_shared_permissions) for why this matters and how to avoid the problem going forward. Once your account is deprovisioned, no one — not even lab admins — can fix permissions on files you own (chmod requires root or the owner, and Sherlock has no user sudo), so any oversight becomes permanently unfixable without an SRCC ticket.
